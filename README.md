# frota-estado

Estado desejado **assinado** dos computadores do time do Grupo Facial. Este repositório é público de propósito: o manifesto não tem segredo, e quem decide se vale é a **assinatura**, não o endereço.

- `estado.json` — o manifesto vigente, dentro de um envelope assinado com Ed25519 (`{ chave, manifesto (base64), assinatura }`). É o único arquivo que as máquinas leem:
  `https://raw.githubusercontent.com/Facial-Academy/frota-estado/main/estado.json`
- `fonte/pacotes.json` (escrito por `quiosque/deploy/publicar-pacote-frota.mjs` do MCP-grupofacial; ninguém edita à mão) lista os pacotes de MCP já assinados; `pacotes/` guarda os arquivos (`pacote-frota-<sha8>.json.gz`, conteúdo PÚBLICO: só o que as máquinas usam). O `renovar.cjs` só copia essa lista para o manifesto: sem a chave dos pacotes ninguém consegue publicar um pacote que as máquinas aceitem, nem com controle deste repositório.
- `fonte/versoes.json` (opcional; escrito por quem publica, com `node ferramentas/assinar-manifesto.cjs assinar-versao …`; ninguém edita à mão) é a versão desejada da extensão `anthropic.claude-code` do VS Code (que embute o Claude Code): `{ "versoes": [ { id, extensao, versao, faixa, alvos, hashes, seq, chave, assinatura } ] }`, já ASSINADA com a chave dos pacotes. O `renovar.cjs` só a copia para o campo de topo `versoes` do manifesto; **sem o arquivo, ou com a lista vazia, nenhuma máquina muda de versão** (e é assim que se para a frota: tire o arquivo). O cliente só age com o VS Code da pessoa fechado, confere hash e remendo e volta sozinho se não conferir (`README` do cliente em `MCP-grupofacial/quiosque/converge`, seção "Versão da extensão").
- `fonte/modulos.json` é o que se quer em cada máquina. Hoje só o tipo `vscode-setting` (uma chave `claudeCode.*` do `settings.json` do VS Code, valor escalar). Editar este arquivo é a única forma de mudar a frota; o `renovar.yml` assina e publica sozinho.
- `chave-publica.json` — as chaves públicas: `2026-10` (assina o manifesto; a privada vive no cofre da empresa e no segredo `FROTA_CHAVE_PRIVADA` deste repositório) e `pacote-2026-11` com `"uso": "pacote"` (assina SÓ os pacotes de MCP; a privada NÃO está neste repositório nem no CI: só no cofre da empresa, e quem publica um pacote a lê de lá).
- `renovar.cjs` + `.github/workflows/renovar.yml` — monta o manifesto, assina e grava `estado.json`: toda segunda-feira (renova a validade de 120 dias), a cada mudança em `fonte/` e sob demanda. O `serial` é a data e hora UTC e só cresce.
- `ferramentas/` — cópia exata do cliente e da ferramenta de assinatura de `Facial-Academy/MCP-grupofacial` (`quiosque/converge/`); `ORIGEM.md` guarda os sha256.

**Como as máquinas usam:** o cliente (`converge.cjs`, instalado como tarefa da própria pessoa) lê `estado.json`, confere a assinatura, recusa `serial` menor e manifesto vencido, e converge: máquina desligada por semanas aplica só o estado final, sem fila. O cliente só aceita o que conhece (chaves `claudeCode.*`, valores escalares); o manifesto nunca manda executar nada.

**Voltar atrás:** edite `fonte/modulos.json` para o valor antigo e deixe o workflow publicar (o `serial` novo é maior, então as máquinas aceitam).
**Chave comprometida:** gere outra com `node ferramentas/assinar-manifesto.cjs gerar-chave <pasta>`, publique a pública junto da antiga em `chave-publica.json`, troque o segredo, remova a antiga depois que a frota aceitar a nova.
